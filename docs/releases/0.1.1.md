# endstone-status-api v0.1.1

Fix live Endstone 0.11 event registration for the optional public chat endpoint. The plugin now uses a concrete `PlayerChatEvent` type annotation (rather than a postponed annotation string), as required by `Plugin.register_events`.

API v1 schema, endpoint defaults, administrator configuration and security model remain unchanged from v0.1.0. This release includes a focused regression test using Endstone's actual event type. Upgrade the wheel in the server Python environment, then restart Endstone to load the corrected listener.
