# endstone-status-api v0.1.0

Initial independent Endstone public HTTP JSON status API, designed for static sites, bots, dashboards, and monitoring consumers. Administrator TOML controls which endpoints and metrics are publicly exposed. No authentication or built-in web UI. Optional bounded chat endpoint. New v1 JSON schema is deliberately unrelated to the old endstone-show-status protocol.

Default listener: 127.0.0.1:19134. To serve external HTTPS clients, configure a reverse proxy or Tunnel (or intentionally change the listener address). See README for the full contract, chat privacy constraints, and configuration.

Install the published wheel in the Python environment used by Endstone, then restart Endstone. The API and HUD plugins may run independently or together.
